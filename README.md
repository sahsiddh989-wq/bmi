# VitalCheck — BMI & Health Calculator

A modern, responsive, client-side health calculator built with plain HTML, CSS and JavaScript.

## Features
- BMI calculation with adult category guidance
- Metric and Imperial units
- Healthy weight range
- Estimated BMR using the Mifflin–St Jeor equation
- Daily calorie estimate based on activity level
- Responsive mobile-friendly interface
- No backend and no personal data transmission

## Run locally
Open `index.html` in a browser.

## Disclaimer
This calculator is for educational purposes only and is not a substitute for professional medical advice.
